# Érika Santos · Designer & Estrategista Visual

Projeto exportado do **Pencil** com suporte completo a **Tailwind CSS**, desenvolvido em **React 19**, **TypeScript** e **Vite**.

## 🎨 Sobre o Projeto

Identidade e presença digital para **Érika Santos (Érika Designer)**, contemplando:
- **Index — Link na Bio** (Desktop & Mobile)
- **Serviços & Metodologia** (Social Media, Identidade Visual, Consultoria & Direção)
- **Contato & Briefing** (Formulário interativo com chips de serviços e links diretos)
- **Componentes reutilizáveis** e selos visuais autorais

---

## 📁 Estrutura de Exportação Pencil (Tailwind)

Os arquivos exportados diretamente do Pencil (`.pen`) em HTML + Tailwind CSS estão disponíveis na pasta `public/`:

- `public/index-desktop.html`: Tela Desktop do Link na Bio / Início
- `public/index-mobile.html`: Versão Mobile do Link na Bio
- `public/servicos-desktop.html`: Página de Serviços e Metodologia (Desktop)
- `public/servicos-mobile.html`: Versão Mobile dos Serviços
- `public/contato-desktop.html`: Tela de Contato e Briefing (Desktop)
- `public/todos-telas.html`: Canvas consolidado com todas as telas exportadas em Tailwind

E a aplicação interativa completa em React está localizada em `src/App.tsx`, com estilização via Tailwind CSS v4.

## 🚀 Como Executar

### Pré-requisitos
- Node.js instalado (v18+)

### Instalação
```bash
npm install
```

### Desenvolvimento
```bash
npm run dev
```

### Build de Produção
```bash
npm run build
```
